# Harbor Lantern Design Tokens

Harbor Lantern is an original, tool-agnostic `DESIGN.md` starter for small product teams. It gives a team a sensible token vocabulary, semantic color roles, component contracts, responsive rules, accessibility checks, and a decision log without requiring a design platform or a build step.

## Included

- `DESIGN.md` — the editable token and handoff starter
- `PRICE.md` — a small productized offer outline
- `LICENSE` — permissive MIT license

## Quick start

1. Copy `DESIGN.md` into a product repository.
2. Replace the Harbor Lantern primitive values with your brand values.
3. Keep semantic and component names stable while implementation evolves.
4. Add decisions and accessibility evidence during review.

The YAML blocks are documentation examples. They intentionally do not require a parser, package manager, hosted service, or account.
